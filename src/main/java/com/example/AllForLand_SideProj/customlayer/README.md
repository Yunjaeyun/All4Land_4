# 사용자 지정 레이어 (현석 담당)

- 메뉴: 지도 화면 상단의 `내 레이어` 버튼 (페이지 이동 없이 패널 전환)
- 바로 진입: `/?menu=custom-layer` (`/custom-layers`는 이 주소로 리다이렉트)
- 화면: `src/main/resources/templates/custom-layer/`
- 스타일: `src/main/resources/static/css/custom-layer/`
- 서버 코드: 현재 패키지 `customlayer`

지도 인스턴스를 유지하며 Thymeleaf 패널과 별도 JavaScript로 메뉴를 전환한다.
`templates/custom-layer/panel.html`, `static/css/custom-layer/panel.css`,
`static/js/custom-layer/panel.js`가 실제 지도에서 사용하는 컴포넌트다.
월/시간 입력, 지도 클릭 및 좌표 입력, 로컬 사진 미리보기를 제공한다.
`static/js/custom-layer/draw.js`는 Google Maps 도형 API를 사용한 그리기 작업 공간이다.
마커·선·다각형·사각형·원을 그려 이름·월·시간을 가진 레이어에 등록할 수 있다.
도형을 선택해 이동·크기/꼭짓점 편집·색상 변경·삭제할 수 있으며 여러 도형을 한 레이어로 묶는다.
등록은 메모리에서만 수행하며 새로고침하면 초기화된다.
사진은 등록 시 레이어에 연결되며 선택 시 상세 패널에서 확인할 수 있다.
레이어 이름·월·시간 수정, 사진 교체/제거, 전체 도형 삭제, 표시 전환을 제공한다.
DB, 사용자 인증 및 서버 사진 업로드는 아직 연결하지 않는다.

## 사용 방법

1. 레이어 이름, 월, 시간을 입력한다.
2. 도구에서 마커, 선, 다각형, 사각형, 원을 선택한다.
3. 마커는 한 번 클릭, 사각형은 두 모서리, 원은 중심과 반지름 끝점을 클릭한다.
4. 선/다각형은 지점을 순서대로 찍고 `그리기 완료` 또는 지도 더블클릭으로 완료한다. Enter도 가능하다.
5. Esc 또는 `그리기 취소`는 진행 중인 도형만 취소한다.
6. `레이어 등록`으로 완성한 미등록 도형을 하나의 레이어에 묶는다.
7. `선택·편집`에서 도형을 클릭하거나 등록 목록에서 레이어를 선택한다.
8. 목록의 `숨기기/표시`, `정보 수정`, `레이어 삭제`로 레이어를 관리한다.
9. `조건 조회`에서 월(전체 월 가능)과 시간대를 지정해 조회한다. 양 끝 시간을 포함하며
   시작보다 종료가 이르면 자정을 넘는 시간대로 해석한다. 월은 레이어에 등록된 월이다.
10. 필터는 조건 조회 탭에서만 적용한다. 추가 탭/지도 메뉴로 돌아가면 필터가 해제되며
    수동 숨김 상태는 유지된다. `조건 초기화`는 전체 월/00:00~23:59로 돌아간다.

노드 테스트: `node --test src/test/js/custom-layer-draw.test.cjs`

## 후속 구현 범위

1. DB 저장 및 새로고침 후 레이어/도형 복원
2. 사용자 인증과 소유자별 접근 제어
3. 사진 서버 업로드 및 영구 저장

향후 API, 서비스, 저장소는 이 패키지 아래 기능별로 추가한다. DB 담당자와
`user_custom_layers` 및 도형 지원을 위한 `custom_layer_features` 설계안을 조율하고 저장소를 연결한다.
화면은 분 단위 시간을 사용하므로 DB의 `hour` 정수 필드와 표현 방식 조율이 필요하다.
