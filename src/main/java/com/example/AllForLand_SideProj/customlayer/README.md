# 나만의 레이어

사용자별 개인 레이어는 하나이며, 그 안에 장소·도형을 여러 개 등록한다.
각 항목은 이름·월·시간·사진·색상·표시 여부를 독립적으로 가진다. 별도의 레이어 생성 UI는 없다.

- 메뉴: 지도 유지 방식의 나만의 장소 지도, `/?menu=custom-layer`
- 화면: `templates/custom-layer/panel.html`
- 동작: `static/js/custom-layer/panel.js`, `draw.js`, `storage.js`
- 스타일: `static/css/custom-layer/panel.css`
- 서버 저장소: `customlayer/storage`, DB 준비: `docs/custom-layer-database.md`

## 사용 흐름

1. 이름·월·시간을 입력하고 마커/선/다각형/사각형/원을 하나 그린다.
2. 선/다각형은 완료 버튼·더블클릭·Enter로 완성한다. Esc는 진행 중인 그리기를 취소한다.
3. `장소·도형 등록`으로 현재 항목을 등록한다. 등록 전에는 다른 도형을 추가할 수 없다.
4. 여러 항목을 등록할 수 있으며 각 항목의 조건은 서로 독립적이다.
5. 등록 목록에서 표시/숨김, 정보 수정, 항목 삭제를 수행한다. 지도에서 도형 위치·색상·꼭짓점을 수정할 수 있다.
6. `조건 조회`는 항목별 월·시간에 적용한다. 양 끝 시간을 포함하고 종료가 시작보다 이르면 자정 통과로 해석한다.
7. 전체 월 및 조건 초기화로 모든 시간대를 조회한다. 추가 탭에서는 조건 필터를 적용하지 않는다.
8. 등록·수정·삭제 후 `서버 저장`을 누르면 현재 개인 레이어 전체를 교체한다.

## API

`GET /api/custom-layers` 및 `PUT /api/custom-layers`는 아래 단일 객체를 사용한다.
빈 개인 레이어는 `{"features":[]}`이며 배열 형태의 다중 레이어 API는 더 이상 사용하지 않는다.

```json
{"features":[{"id":1,"name":"노을 명소","month":9,"time":"18:00","visible":true,"photo":null,
  "shape":{"type":"marker","color":"#247b65","position":{"lat":51.5,"lng":-0.1}}}]}
```

`GET /api/custom-layers?month=9&start=17:00&end=19:00`은 같은 객체 안에서 조건에 맞는 항목만 반환한다.
필터 결과를 저장본으로 자동 교체하지 않는다. 저장은 항상 전체 항목 기준이다.
최대 1,000항목, 항목별 10,000꼭짓점, 사진별 5MB, 사진 Base64 전송량 총 20MB를 제한한다.
기본은 세션별 메모리 저장이며 새로고침은 복원되고 서버 재시작·세션 만료 시 초기화된다.
`layer-db`는 로그인 사용자별 영구 저장을 위한 준비 모드다. 로그인/운영 DB 연결은 아직 수행하지 않았다.
사진은 항목별 Data URL로 보관하며 별도 파일 업로드는 후속 작업이다.

기존 다중 레이어 메모리 저장본과는 호환되지 않는다. 서버 재시작 후 새 구조로 사용한다.
이전 준비 SQL을 적용한 DB의 기존 항목은 자동 삭제·변환하지 않으며 별도 마이그레이션 대상이다.
